# Security policy

Please report vulnerabilities privately to **security@layerhop.com**, not in public issues. Include the version, a
description of the issue and, if you can, steps to reproduce it. We aim to acknowledge reports within three business
days and will keep you informed while we work on a fix.

Only the latest released version receives security fixes.

Hopstore does not encrypt data itself: protect the bucket and the local directory with your storage provider's access
controls and encryption, and keep S3 credentials out of source control.
